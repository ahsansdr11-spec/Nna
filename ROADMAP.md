# Roadmap

This is a living document of where Nna is headed. Suggestions are welcome via
[issues](https://github.com/ahsansdr11-spec/Nna/issues) and pull requests.

## Planned

- **Plugin system** — let the community add new extractors and post-processors
  without touching core code.
- **More supported platforms** — expand the 26+ list with community-requested
  sites and regional services.
- **Authentication** — optional login to unlock private / age-restricted
  content and per-user history, with secure credential handling.
- **Mobile app** — a native or PWA mobile client for iOS / Android.
- **API improvements** — a stabilized, versioned REST / JSON API, better docs,
  and rate limiting / keys for public use.

## Under consideration

- Subtitle / caption downloads.
- Batch playlist downloads with resume.
- Self-hosted federation between Nna instances.
- Webhooks for download completion.
